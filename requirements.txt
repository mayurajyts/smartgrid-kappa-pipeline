# Shared Python dependencies for the non-Spark services (simulators, batch
# loader, API). Pinned to minor versions so a clean clone six months from now
# resolves to the same behaviour — a reproducibility requirement, not fussiness.
#
# PySpark is deliberately ABSENT. The Spark jobs run inside the Spark cluster
# image, whose PySpark version must match the cluster exactly; installing a
# second copy here would invite a driver/worker version mismatch, which
# surfaces as an opaque serialisation error at runtime.

# Config — typed, validated, environment-driven settings (common/config.py)
pydantic~=2.9
pydantic-settings~=2.6

# Kafka client. confluent-kafka (librdkafka) rather than the pure-Python
# kafka-python: it is the client matching the Confluent broker in use, and it
# exposes the per-record delivery callbacks and record headers this design needs
# for the correlation-id trace. Prebuilt wheels exist for CPython 3.11 on
# Windows/macOS/Linux, so no compiler is needed on a marker's machine.
confluent-kafka~=2.5

# Observability (§8)
structlog~=24.4
prometheus-client~=0.21

# Tests
pytest~=8.3
